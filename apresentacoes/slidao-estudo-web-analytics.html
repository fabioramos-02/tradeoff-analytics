Recomendação · ADR-002

Duas arquiteturas, um estudo

Matomo continua padrão do parque.
Xvia ganha PostHog em paralelo.
Não é substituição. Não é preferência tecnológica. É reconhecimento de que web analytics e product analytics são eixos distintos.
✓

Parque existente

Matomo On-Premise como padrão único — portais institucionais, sites gov, serviços de conteúdo. Continuidade preservada, cookieless CNIL, auditoria verificável.

◈

Portal Xvia

Matomo + PostHog em paralelo. Matomo → audiência anônima. PostHog → jornada identificada, funil transacional, feature flags, replay consentido.

SETDIG · Estudo Web Analytics 06 / 10
Arquitetura-alvo

Ambas sob custódia do Estado. Zero transferência internacional.

▸ Parque

Cidadão → Matomo → MySQL
Redis (fila) ↔ Arquivamento
MySQL réplica → BI corporativo

3 componentes — PHP + MySQL + Redis. QueuedTracking absorve pico 30×. Réplica de leitura isola BI. Padrão cookieless CNIL.

▸ Xvia (superapp cidadão)

Cidadão auth → Matomo + PostHog
Kafka → ClickHouse → Object storage (replay)

6 componentes PostHog — Django + PG + ClickHouse + Kafka + Redis + MinIO. Session replay opt-in + mascaramento agressivo padrão. Feature flags e experimentação estruturada.

♦
Governança do dado duplicado: cada capability instrumentada em UMA ferramenta; fonte primária declarada por métrica; retenção sincronizada; reconciliação mensal (divergência ≤ 15 %).

SETDIG · Estudo Web Analytics 08 / 10
Riscos top-5

Trade-offs assumidos conscientemente

  • R-11
    Captura acidental de dado sensível em session replay. Prob. média · Impacto crítico. Mitigado por mascaramento agressivo padrão + opt-in explícito + DPIA + homologação SegInfo antes de ativar.
  • R-17
    LCP do Xvia degrada > 75 ms sustentado por overhead do 2º script. Prob. baixa · Impacto alto. Gatilho G9 aciona reavaliação em 60 dias.
  • R-18
    STI não sustenta stack PostHog (ClickHouse + Kafka + coordenadores). Prob. média · Impacto alto. Plano de capacitação + reserva orçamentária para suporte especializado + fallback PostHog Cloud EU.
  • R-19
    Divergência Matomo × PostHog no Xvia gera confusão em relatórios executivos. Governança explícita de fonte por métrica; reconciliação mensal com limite ≤ 15 %.
  • R-20
    PostHog descontinua modalidade auto-hospedada (movimento já iniciado em 2023 com fim do suporte K8s). Monitoramento contínuo (G11) + fallback Cloud EU com RIPD específico.
