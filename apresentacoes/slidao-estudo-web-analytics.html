Riscos e controles

O que pode dar errado — e como vamos controlar

Proteção dos dados

A reprodução da navegação do cidadão pode registrar informações sensíveis.
Como controlar: proteção automática + autorização explícita + avaliação de impacto.

Complexidade

O PostHog exige uma estrutura mais complexa para funcionar.
Como controlar: capacitação da equipe + suporte especializado + alternativa de contingência.

Velocidade

Duas ferramentas podem aumentar o tempo de carregamento do portal.
Como controlar: acompanhar continuamente o desempenho.

Números diferentes

As ferramentas podem apresentar resultados diferentes para o mesmo indicador.
Como controlar: definir uma fonte oficial para cada indicador.
O risco não desaparece. Ele passa a ser controlado.
